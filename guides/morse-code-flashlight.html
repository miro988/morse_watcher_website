Morse Code Flashlight: How to Send and Read Morse With Light

Every flashlight can send Morse code. A short flash is a dot, a flash three times as long is a dash, and the dark gaps between them split the letters and words. This guide covers the timing, a full chart, how to send by hand, and how to turn your phone into a Morse code flashlight that sends and reads messages.

1. Flashlight Morse code timing

Morse code is all about rhythm. Pick one steady beat, called a unit, and build everything from it. By hand, a unit of about half a second is easy to send and easy to read.

Element Light Length By hand (unit ≈ 0.5 s)
Dot • ON 1 unit ~0.5 sec
Dash – ON 3 units ~1.5 sec
Gap inside a letter OFF 1 unit ~0.5 sec
Gap between letters OFF 3 units ~1.5 sec
Gap between words OFF 7 units ~3.5 sec

The exact speed matters less than keeping the ratios steady. A reader can follow a slow sender easily, but uneven dots and dashes are hard to tell apart.

3. How to send Morse code with a flashlight

  1. Use a light with a push button. A button you hold down for "on" (a momentary switch) is much easier to time than a click switch. No button? Cover and uncover the lens with your hand.
  2. Agree on a start. A few quick flashes before the message tells the reader to pay attention.
  3. Flash each letter from the chart: 1 unit for a dot, 3 for a dash, 1 unit dark in between.
  4. Pause 3 units between letters and 7 units between words. These pauses are what make a message readable.
  5. Aim straight at the reader and send from the darkest spot you can find. A dim light against a dark background is easier to read than a bright one in streetlights.

5. How to read Morse code from a flashlight

Reading is harder than sending. Write a dot for each short flash and a dash for each long one, and start a new letter at every longer gap. Ask the sender to slow down and repeat. For a full walkthrough, by eye and with your camera, read how to decode Morse code from a flashing light.

6. Where a Morse code flashlight is useful

  • Hiking & camping: Message between campsites or across open ground at night.
  • Scouts & games: Decode a blinking light at camp, in escape rooms or in night games. Working on a badge? See the Signs, Signals, and Codes merit badge guide.
  • Learning Morse: Practice sending and check your reading against live decoding.

7. Buying a Morse code flashlight

Toy and gift "Morse code flashlights" are regular flashlights with a separate Morse key button and a printed chart. They're fun for learning, but any flashlight with a push button sends the same code, and a phone app can time the flashes for you.

FAQ

How do you do Morse code with a flashlight?

Flash the light on briefly for a dot and three times as long for a dash. Keep it off for one unit between dots and dashes, three units between letters and seven units between words.

How long is a dot and a dash?

A dash is three times as long as a dot. By hand, a dot of about half a second and a dash of about one and a half seconds is easy to send and easy to read.

Can my phone be a Morse code flashlight?

Yes. With Morse Watcher, type a message, hit send, and Morse Watcher flashes your torch in Morse code.

Is a Morse code torch the same thing?

Yes. Torch is the word used in the UK, Australia and New Zealand. The timing and the code are the same.
